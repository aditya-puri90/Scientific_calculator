 🖩 **Scientific Calculator**

A sleek, dark-themed Scientific Calculator application built with Flutter using the Provider state management pattern. This application seamlessly handles standard mathematical computations alongside advanced scientific functions. 

 🚀 Features

* **Sleek Dark Theme**: Designed with a modern, eye-friendly dark user interface.
* **Basic Arithmetic**: Reliable execution of addition, subtraction, multiplication, and division.
* **Advanced Scientific Functions**: Complete support for trigonometric (sin, cos, tan) and logarithmic operations.
* **State Management**: Built using the Provider pattern for efficient, reactive UI updates.

 🛠️ **Tech Stack & Dependencies**

* **Framework**: Flutter (Dart)
* **State Management**: Provider
* **Expression Parser**: math_expressions (or your specific parsing package)
